Professional ethics

American Library Association. (2021). Code of ethics of the American Library Association. Read the current official code (checked October 27, 2026).

The code was amended June 29, 2021, after the assigned textbook edition. The current ninth principle addresses dignity, rights, equity, and justice. The lesson treats the code as a framework for judgment, not a complete answer to every situation. The fictional photograph example supplies no legal determination.

Design and acknowledgments

The learning sequence, scenarios, explanations, diagrams, and community-display illustration are original instructional adaptations. The five-part route is a teaching aid, not a formula attributed to the textbook. Cedar Crossing, its project, and proposed actions are fictional; no invented result is presented as measured evidence.

UNT colors and the university mark follow the supplied course visual identity and the UNT Brand Reference Guide. The existing logo asset is reproduced without altering the mark.

Recorded AI narration uses Kokoro v1.0, voice af_heart. No user voice was cloned. Each chapter has a separate local MP3 and synchronized VTT captions. The site needs no speech API or external audio service.

Short, learner-controlled segments and relevant signaling draw on Brame, C. J. (2016), Effective educational videos: Principles and guidelines for maximizing student learning from video content, CBE Life Sciences Education, 15(4), es6. Read the article.

Access and learning controls

Choose listening, reading, or both. Audio never starts on page load. Use Play, Pause, Replay, playback speed, volume, mute, and captions controls. Navigation and practice pause narration. Only one chapter recording plays at a time. The full transcript includes all narration, diagram text and descriptions, expanded explanations, practice, and game feedback.

Activities are optional and can be skipped. Library Shift starts untimed; timed play is optional. Pause, restart, independent game sound, a shortcut off switch, and reduced motion are available. Buttons support keyboard operation and visible focus. Important meaning is conveyed in text as well as color.

Your last chapter and separate game best scores are saved in this browser, if browser storage is available. Blocked storage falls back to the current visit. Nothing is sent to Canvas; there is no completion record, grade, account, analytics script, or shared leaderboard in the lesson. Standard hosting services may retain their own access logs.

Accessibility guidance: W3C audio and video media guidance and WCAG 2.2 quick reference. Automated checks and manual keyboard, responsive-layout, and audio-control checks support review; they do not constitute a formal accessibility certification.

If an activity or audio control is difficult to use, the complete reading alternative covers the same instructional material.
